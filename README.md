# Explorateur de fichier en Session

Le but de ces scripts est de gerer l'explorateur de fichier windows 11 comme un navigateur.
En aillant plusieurs onglets d'ouvert dans l'explorateur, la fermeture complete de celui ci déclencherai la sauvegarde de la session, et a la prochaine réouverture de l'explorateur, tout les onglets précédemment ouvert serai restauré dans une meme fenetre. 

## Méthodes

- ✅ Script shells pour la sauvegarde 
- ❌ Script shell pour la restauration. En attente d'une API Windows spécifique à l'explorateur de fichier Windows 11, la restauration des onglets via script shell se fais dans *x* nouvelles fenetres d'explorateur, et pas dans une meme fenetre avec *x* onglet réouvert. 
- ✅ AutoHotKey script pour la restauration
